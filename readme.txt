**ScripStore** es una plataforma e-commerce moderna, dinámica y responsiva orientada a ofrecer una experiencia de compra fluida e intuitiva. El proyecto integra un catálogo de productos en tiempo real, sincronización con base de datos y un sistema de gestión de compras interactivo.

---

## ✨ Características Principales

* **🛒 Carrito de Compras Dinámico:**
  * Agregar, incrementar, decrementar y eliminar productos de forma inmediata.
  * Cálculo automático del subtotal, impuestos y total de la orden en tiempo real.
  * Persistencia de datos local para mantener los artículos guardados ante recargas de página.

* **🛍️ Catálogo y Exploración de Productos:**
  * Visualización de productos organizados por categorías.
  * Vista detallada de cada ítem con stock, descripciones y precios actualizados.

* **🎨 Diseño y Experiencia de Usuario (UI/UX):**
  * Interfaz totalmente adaptativa (*Responsive Design*) optimizada para móviles, tablets y escritorio.
  * Feedback visual inmediato en cada interacción (notificaciones al añadir al carrito, estados de carga).

* **🔥 Integración con Base de Datos:**
  * Conexión con **Firebase / Cloud Firestore** para el almacenamiento de productos y órdenes.
  * Consultas optimizadas para una carga rápida de información.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
* **Backend / Servicios:** Node.js, Firebase (Firestore & Authentication)
* **Despliegue:** Vercel
